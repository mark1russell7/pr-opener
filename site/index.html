PR Opener

A Chrome extension that opens a pull request from the URL bar. Type pull, press Tab, type a PR number and press Enter. Try it below: the real code of the extension runs in this page.

      Configure the repos

      This is the real options page of the extension. Add, change or move a repo, and select Save. The suggestions in the URL bar then use the new list. The first repo is the default.

      Options page options.html

      chrome.storage.sync

      
            
      Save writes this value. Open again shows it, and removes each change that you did not save.

      The stand-in
      
            
        
              
      • This page draws the URL bar and the tabs. It sets its own chrome object before it loads the scripts.
        • 
              
      • That object fires the omnibox events, keeps the storage in memory and records the tab calls.
        • 
              
      • It has no storage quota and no sync between devices. Chrome also shows fewer rows when the list is long.
